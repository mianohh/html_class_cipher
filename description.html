Description List

HTML
HTML is a markup language for creating web pages. It is the standard markup language for documents designed to be displayed in a web browser. It is a client-side language.
Java
Java is a high-level, object-oriented programming language that is designed to be platform-independent. It is widely used for developing web applications, mobile applications, and enterprise software.
JavaScript
JavaScript is a programming language that is commonly used to create interactive effects within web browsers. It is a versatile language that can be used for both front-end and back-end development.
SQL
SQL is a domain-specific language used in programming and designed for managing data held in a relational database management system (RDBMS).
